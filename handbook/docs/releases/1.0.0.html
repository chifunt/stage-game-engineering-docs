Reviewable Result​

This release carries the previously unreleased 0.7 redesign and correctness repairs forward into the owner-accepted 1.x compatibility contract. The readiness review explains the recommendation; compatibility owns the accepted terms.

The agent has prepared package versions, both Node lockfiles, the method version, current references, changelog, compatibility inventory, and ADR 0066. Local preparation preceded the owner's September 27 instruction to release, publish, and update the installed plugin. The canonical source remains private; public documentation continues through the scoped mirror.
