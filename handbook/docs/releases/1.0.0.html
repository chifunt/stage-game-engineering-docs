Reviewable Result​

This release carries the previously unreleased 0.7 redesign and correctness repairs forward into the owner-accepted 1.x compatibility contract. The owner calls Salvageist's pilot successful; its nine-change retrospective and workflow-cost follow-up provide the practical basis for proceeding. An intermediate 0.7 publication is unnecessary. The readiness review explains the recommendation; compatibility owns the accepted terms.

Salvageist's applied lessons keep verification proportional in the actual runner: include the whole task delta, stop costly dependent stages after prerequisite failure, use compact completion signals, and reuse conclusive evidence only when its relevant inputs and policy permit. Keep recovery notes current and assign shared integration/release one owner when delegation is useful and authorized. Instructions remain model-neutral; no mandatory agent chain or new artifact is introduced. Unity guidance already carries direct-scenario, output-protection, and comparable cold/steady-state measurement lessons from the pilot.

The agent has prepared package versions, both Node lockfiles, the method version, current references, changelog, compatibility inventory, and ADR 0066. Local preparation preceded the owner's September 27 instruction to release, publish, and update the installed plugin. The canonical source remains private; public documentation continues through the scoped mirror.
