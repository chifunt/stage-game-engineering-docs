STAGE Architecture Decisions

Current Method-Shape Decision​

ADR 0050 separates a small universal safety kernel from optional interoperability contracts and practitioner guidance. It supersedes any earlier implication that STAGE's recommended architecture, full delivery prose, or optional artifacts are universal conformance requirements. Earlier ADRs remain evidence and guidance unless an adopted optional contract depends on them.

Current Authority Decision​

ADR 0051 evaluates authority at the proposed operation. Unresolved provenance constrains nearby work without erasing separate narrow authority, and narrow authority never widens into adjacent mutation, replacement, or regeneration.

Current Player-Experience Decision​

ADR 0053 requires human-led intent formation before substantial implementation and bounds automated, owner, and representative-player claims. It complements ADR 0052, which requires a thin complete loop and direct human play before a new or materially changed player-facing premise expands. Mechanical success cannot grant product acceptance. ADR 0054 adds a concrete systems-heavy reasoning loop while rejecting a universal fun formula or score.

Current Mapping Decision​

ADR 0039 keeps project maps as durable orientation surfaces. Exact run coordinates live in one canonical verification history or an explicitly revision-bound audit or release record rather than being copied across maps.

Current Visual Decision​

ADR 0048 is the current routing decision: visual implementation, diagnosis, audits, and polish use the ordinary delivery workflow. ADR 0041 still supplies its scoping rule for outcome-free standing-coverage requests. ADR 0040 remains the current ownership decision for visual capture and export artifacts: retain them only for a concrete decision or operation. ADR 0038 keeps persistent visual UI in the ordinary project backlog when its own player, author, or developer job justifies it. ADR 0025 retires the detached evidence-package path. Earlier visual ADRs remain below as decision history, not alternative recipes.

Current Workflow-Control Decision​

ADR 0049 bounds valid positive inspection by decision-bearing uncertainty without imposing a fixed action budget. ADR 0044 requires route rejection to be classified before detailed orientation and makes accepted fragments preservation constraints rather than replacement scope. ADR 0043 makes explicit human rejection of a route's utility terminal for that route. ADR 0042 makes mechanical and authority stop conditions actual control flow: the blocked branch terminates instead of continuing after a warning under a narrower label. ADR 0047 and ADR 0046 keep always-visible routing metadata separate from the policy loaded with a selected skill.

Current Solo Attention Decision​

ADR 0055 adds the optional Stage Director's Flow around ordinary delivery. It keeps raw Cues, human gameplay Dialogue, Ready work, active delivery, Rehearsal, the Director's Call, and source-control Checkpoints distinct without requiring a tracker, sprint cadence, story points, or machine-readable work-item schema.

Current Quality-Gate Decision​

ADR 0056 separates Source, Model, Engine, Consumer, Distribution, and Director gates. Checks are selected by claim and production boundary; automated green status cannot grant product acceptance, and agents cannot weaken quality policy to obtain a pass.

Current Change-Integration And Release-Identity Decision​

ADR 0057 recommends short-lived work-item branches, isolated worktrees, bounded agent concurrency, explicit Unity asset ownership, and serial integration. Product release version, exact build identity, and data contract versions remain separate, while release approval and publication stay human-owned. ADR 0063 specializes that guidance for this repository by requiring Conventional Commits. ADR 0064 consumes that metadata only to prepare a human-completed draft release PR; tags, GitHub Releases, package refresh, and publication remain explicit maintainer actions.

Current Task-Continuity Decision​

ADR 0058 treats conversation history as disposable working context. Durable project knowledge lives in a short Project Context Spine, unfinished work crosses task boundaries through revision-bound handoffs, and a fresh-task Orientation Check must reconcile current source before mutation.

Current Agent-Workflow Decision​

ADR 0059 keeps ordinary change delivery implicit while adding explicit read-only orientation and check-only verification routes. Project mapping remains a separate explicit workflow, and all three companion routes stop before unauthorized mutation.

Current Documentation-Surface Decision​

ADR 0060 keeps one canonical repository source chain while providing compact agent procedures and a derived Docusaurus reading interface for humans. External trackers and knowledge bases remain optional noncanonical attention views.

Current Documentation-Publication Decision​

ADR 0062 keeps the quality-gated public mirror established by ADR 0061 and serves it through Cloudflare Pages. The hosting integration sees only the screened generated repository; canonical private source remains disconnected and authoritative.
