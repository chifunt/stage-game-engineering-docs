Map Profiles

Map profiles control artifact depth, not architecture or project quality.

They apply only after repeated coordination, ownership, or operation cost earns a persistent project map. The Safety Kernel does not require a map.

Compact​

Use for a small project, prototype, focused tool, or repository whose important boundaries fit in one short map.

Required emphasis:

  • purpose and human authority;
  • canonical vocabulary that prevents real ambiguity;
  • the smallest honest domain/owner map;
  • safe operations and known unavailable operations;
  • ownership boundaries that prevent accidental overwrite;
  • relevant evidence surfaces and gaps.

Do not add empty domain taxonomies, factories, registries, or authoring tools.

Standard​

Use for a maintained game with multiple material runtime, authoring, or lifecycle boundaries.

Add:

  • domain responsibilities and dependencies;
  • composition, persistent/transient state, reset, and teardown;
  • authoring surfaces;
  • explicit decision rights;
  • risks and open questions.

Extended​

Use when the project coordinates multiple editors or middleware tools, generated artifacts, platform-specific delivery, external audits, or high-impact production operations.

Add:

  • declared and effective toolchains;
  • formal-source and rehearsal-copy rules;
  • generation/import pipelines and authority;
  • operation effects, readiness, and recovery;
  • evidence provenance and platform scope;
  • external review or audit metadata when applicable.

Selection Rule​

Choose the least detailed profile that makes current coordination and change risk legible. Expand one risky section before expanding the whole map. Profile changes are reviewable documentation changes, not release promotions or transferability claims.

Profile depth does not turn a project map into a test ledger. All profiles describe durable operation capability and link to one canonical verification history. Exact counts, revisions, timestamps, hashes, and per-run outcomes belong in that history or in a deliberately revision-bound audit or release record.
